# OEEC - Observatório de Eficiência Energética das Cidades

Plataforma SaaS de inteligência energética, ESG e climática para cidades, indústrias e organizações, baseada em metodologias do GHG Protocol.

## Estrutura do Projeto

Este repositório contém a documentação base estruturada para que agentes de IA possam construir a aplicação:

- [Mapa_Estrutural.md](Mapa_Estrutural.md): Define a arquitetura de software, estrutura de banco de dados, mapeamento de UI/UX e fluxo de dados.
- [Descricao_Modulos.md](Descricao_Modulos.md): Detalhamento dos módulos do GHG Protocol, requisitos de dados e lógicas de cálculo.

## Objetivo

O OEEC visa ser uma ferramenta central para gestão climática e de eficiência energética, integrando indicadores ESG e gerando rankings nacionais de desempenho.
